# Лиды на недвижимость ОАЭ и Дубая

Сервис круглосуточно проверяет комментарии, обсуждения и сообщения в профильных
сообществах VK и Telegram. Найденные обращения отправляются в Telegram-бота
первым двум пользователям, которые нажали `/start`.

Основные маркеры:

- «Цена?», «Сколько стоит?»;
- «Срок сдачи?», `handover`;
- «Можно планировку?», `floor plan`;
- «Можно в ипотеку?», «Есть рассрочка?», «Какой первый взнос?»;
- «Хочу купить квартиру в Дубае», «Есть варианты с 2 спальнями?»;
- аналогичные запросы на русском и английском.

Рекламные публикации агентов, вакансии, туры и сообщения продавцов отсекаются.
Короткий комментарий вроде «Цена?» считается лидом только внутри контекста
недвижимости ОАЭ.

## Источники

- `VK_SOURCES` — стартовый приоритетный список VK-сообществ.
- `discovery_candidates.json` — расширенный каталог найденных VK-групп. Бот
  подключает все подходящие группы к основной ротации при
  `VK_INCLUDE_ALL_CANDIDATES=true` (значение по умолчанию).
- `TELEGRAM_SOURCES` — публичные Telegram-каналы и чаты.
- В стандартную ротацию включены профильные каналы и русскоязычные сообщества
  Дубая, ОАЭ, инвестиций, бизнеса и релокации. Для активных чатов используется
  отдельная глубина `TELEGRAM_CHAT_MESSAGE_LIMIT`.
- `regional_sources.json` — дополнительный региональный каталог, который не
  заменяет основные источники. Он содержит инвестиционные, предпринимательские,
  финансовые и риелторские сообщества 16 российских городов. VK и Telegram
  проверяются отдельными очередями с настройками `REGIONAL_BATCH_SIZE` и
  `TELEGRAM_REGIONAL_SOURCE_BATCH_SIZE`.

Для регионального источника недостаточно локального вопроса о цене или ипотеке:
в сообщении либо в обсуждаемой публикации обязательно должен присутствовать
контекст покупки недвижимости в Дубае или ОАЭ.

Если обращение явно содержит признаки клиента из России — например, Москву,
оплату рублями или перевод денег из РФ, — лид получает направление
`Россия → ОАЭ` и повышенный приоритет.

Telegram Bot API не позволяет читать произвольные чужие каналы. Поэтому
`TG_BOT_TOKEN` используется для команд и уведомлений, а чтение Telegram выполняет
авторизованная пользовательская сессия Telethon (`TELEGRAM_API_ID`,
`TELEGRAM_API_HASH` и файл сессии в `data/`).

## Запуск

1. Скопировать `.env.example` в `.env` и заполнить секреты.
2. Установить зависимости: `python -m pip install -r requirements.txt`.
3. Проверить конфигурацию: `python bot.py --check-config`.
4. Запустить один проход без уведомлений: `python bot.py --once --dry-run`.
5. Запустить постоянно: `python bot.py`.

Команды бота: `/start`, `/check`, `/status`, `/pipeline`, `/help`.

## Сервер

Сервис устанавливается в `/opt/uae-real-estate-lead-bot` как
`uae-real-estate-lead-bot.service`.

Для деплоя задайте локально `SERVER_HOST`, `SERVER_USER` и `SERVER_PASSWORD`,
затем выполните `python deploy_server.py`. `.env`, пользовательская Telegram-
сессия и рабочие данные не публикуются в GitHub.
